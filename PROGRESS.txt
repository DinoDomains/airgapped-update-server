KNOWN QUIRKS / LESSONS
----------------------
- Run server always with AIRGAP_STORE_DIR set; otherwise a fresh CA is
  created in ./data and existing agents fail with BadSignature
- mirror.rockylinux.org is IPv6-only/unreliable under NAT - use IPv4
  mirrors (dl.rockylinux.org)
- Use pkill -x (not pkill -f) to avoid killing the invoking shell
- Rocky agents lack /proc/sys/kernel/arch - uname -m fallback needed
